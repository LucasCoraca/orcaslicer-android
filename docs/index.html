Features

Everything you use on the desktop.

This is Orca's own code, so the features are the same: the profiles, the gizmos, every setting and the calibration tools.

Same slicing engine

libslic3r is built from upstream without changes, with the same algorithms, the same printer profiles and the same G-code as the desktop version.

Same interface

Orca's wxWidgets GUI runs on Android through wxWidgets' Qt backend: Prepare, Preview, gizmos, presets and the settings tabs.

Built for touch

Tap to select and drag to move. Long-press for context menus. Pinch to zoom, two fingers to pan, twist to rotate. Kinetic scrolling, and the back button closes dialogs.

Phones and tablets

Tablets get the full desktop layout. Phones get a compact one: settings full screen behind a "3D view" button, a vertical gizmo column, and compact bars.

System file picker

Open STL and 3MF files from local storage, Google Drive or any document provider through Android's Storage Access Framework.

Native and multi-core

Compiled C++ for arm64 with OpenGL ES 3 rendering. Slicing uses every CPU core through TBB, like the desktop version.

How it works

A port, not a rewrite.

OrcaSlicer's interface is written against wxWidgets. wxWidgets has no Android backend, but it has a Qt one, and Qt runs on Android. The port makes that chain work on a touch screen.

  • wxWidgets on Qt, fixed for AndroidDPI-correct painting, full-screen windows and on-screen dialogs, touch converted to mouse and gesture events, kinetic scrolling, and shared GL contexts for the 3D views.
  • OpenGL ES 3Orca's GLSL shaders are converted to GLSL ES, with a GLES loader and ES-safe render paths in the 3D scene and the G-code viewer.
  • Android servicesJava bridges for the system WebView and the Keystore. The native file picker handles content:// URIs, and saved files are copied back through the Storage Access Framework.
  • Two patches, pinned upstreamEvery change is kept as one patch for OrcaSlicer and one for wxWidgets, so the port can follow upstream.

Get it

Install or build it yourself.

Preview builds are published on GitHub Releases. The whole port is open source under the AGPL, the same licence as OrcaSlicer.

Install the APK

  1. Download OrcaSlicer-android-arm64-preview.apk. It is the right file for almost every phone and tablet. Use x86_64 for emulators and Chromebooks.
  2. Allow your browser or file manager to install apps when Android asks.
  3. Open Orca Slicer. The first start unpacks the printer profiles, which takes a few seconds.

Requires Android 9 or newer and OpenGL ES 3.0. 6 GB of RAM or more is recommended for large models.

Build from source

# Linux host · Android NDK 29 · Qt 6.8.3 for Android · JDK 17
git clone https://github.com/LucasCoraca/orcaslicer-android
cd orcaslicer-android
./fetch-sources.sh        # pinned upstream + patches
./configure-deps.sh arm64-v8a && ./run-deps.sh arm64
./configure-wx.sh arm64-v8a
ninja -C build/wx-arm64-v8a install
./configure-app.sh arm64-v8a
./build-all.sh arm64-v8a  # → dist/*.apk

Prerequisites and environment variables are listed in the README.

Status

Preview quality, and improving.

Most of Orca already works. Here is what is known to be missing.

Working
  • Model import (STL, 3MF), handy models and primitives
  • Selection, arrange, and the move, rotate and scale gizmos
  • All printer, filament and process settings, and presets
  • Slicing, with the result, the legend and the layer sliders
  • Setup wizard, Home page, menus and dialogs
  • Touch gestures and the compact phone layout
Not yet
  • Bambu Lab cloud and network plugin (closed-source desktop binary)
  • Printer camera view
  • Some web dialogs, such as printer selection, on narrow phone screens
  • Landscape phones and foldables: works, but not tuned yet
  • Large models are slower than on a desktop
  • On emulators with a software GPU the Preview toolpaths render black, so these screenshots show the Prepare view
